组卷抓题工具 · Windows 完整包（含答案抓取）

一、首次使用：按文件名前面的数字操作
1. 将整个压缩包解压到一个固定文件夹，例如 D:/组卷抓题工具。
   不要直接在压缩软件里运行。文件夹应可写，建议不要放在 Program Files 或同步网盘里。
2. 双击“1-一键安装.cmd”，保持联网并等待出现“安装完成”。
   安装器自动下载本工具需要的 Node.js 运行环境、安装依赖并编译源码。
   优先使用电脑已有的 Chrome 或 Edge；没有可用浏览器时自动下载专用 Chromium。
   无需另行下载原项目，不需要 Git、Python、AI 客户端或 API 密钥。
3. 双击“2-登录组卷网.cmd”，在浏览器中用微信扫码。
   尽量在60秒内完成；超时后重新运行即可。登录成功后保留工具浏览器。
4. 双击“3-编辑任务.cmd”，根据需要修改并保存“任务配置.json”。
   第一次可以保持默认：初中全等三角形，计划取3道题，优先中档难度。
5. 双击“4-开始抓题.cmd”。默认同时获取所选题目在网站上可查看的答案、解析。
   窗口会显示知识点、实际取题数、答案保存数量和保存位置。
6. 双击“5-查看结果.cmd”，在默认浏览器打开最近一批题目的总览。
   总览有题目截图、答案与解析、获取状态、出处链接和打印按钮，可另存为 PDF。
7. 用完后双击“6-关闭浏览器.cmd”，关闭工具启动的浏览器。

二、电脑要求
支持 Windows 11 64位 x64 电脑。此包不适用于 macOS、Linux 或 Windows ARM。
首次安装需要联网，下载量取决于是否需要专用浏览器，请预留约1GB磁盘空间。
安装到当前文件夹，不要求预先安装 Node.js，也不需要管理员权限。
这是联网安装包，不是离线免安装包。安装后正常抓题仍需联网。
下载失败时，检查网络后重新双击“一键安装”；已抓取的结果不会因此删除。

三、如何修改任务
“任务配置.json”的默认内容：
{
  "grade": "middle",
  "points": ["zsd5391"],
  "difficulty": "中档",
  "perPoint": 3,
  "maxPages": 3,
  "seen": []
}

grade：middle=初中，high=高中。
points：知识点编号数组，最多4个。zsd5391 对应初中全等三角形。
difficulty：填写“基础”“中档”或“较难”。优先选匹配标签的题，不够时会用其他难度补充。
perPoint：每个知识点计划取几道，范围1～10。
maxPages：每个知识点最多查看几页，范围1～10。
seen：需要排除的已有题目 qid 数组，初次使用保持 []。
answers（可选）：不填写时默认取答案。若只想取题，在 seen 行末加逗号，
再增加一行 "answers": false；填写 true 可重新开启。true/false 不加引号。
原有任务配置无需修改即可抓答案。“检查配置”不会打开答案或消耗答案查看次数。

双击“查找知识点.cmd”，输入关键词和学段，找到合适的 zsd 编号后填入 points。
可先双击“检查配置.cmd”，核对知识点名称；这个入口不联网抓题。
无需填写项目路径、浏览器路径或输出路径，程序会根据解压位置自动确定。
每次抓题都会新建一个带时间的结果文件夹，避免覆盖前一次结果。
修改 JSON 时必须保留英文双引号和逗号，不要写注释，也不要改成 .txt 后缀。

四、按关键词自动匹配（可选）
将 points 删除或设为 []，并添加：
  "keywords": ["全等三角形的判定", "全等三角形"],
  "maxPoints": 1
keywords 第一个词是考查方法，第二个词是课题；maxPoints 为匹配数量，范围1～4。
自动匹配可能偏离要求，请先运行“检查配置.cmd”核对；指定知识点编号更容易控制范围。
points 非空时会优先使用 points。

五、抓到的题在哪里
所有结果保存在本工具文件夹的 output 下，按时间分批：
  output/日期-时间/index.html：这一批的题目总览。
  output/日期-时间/zujuan.json：包含题干、来源、难度、知识点的题目清单。
  output/日期-时间/z01/question.png：第1题截图，以此类推。
  output/日期-时间/z01/answer.png：第1题已保存的答案与解析截图，获取成功时才有。
  output/日期-时间/z01/fig_1.*：单独保存的题图。
“5-查看结果.cmd”打开最近一批；查看旧结果可直接打开对应目录的 index.html。
本工具保存组卷网页面提供的答案与解析，不自动解题，不生成可编辑的 Word 讲义。
不需要 Codex、其他 AI 客户端、API 密钥或额外识别服务。
答案以图片保存，不能保证每道题都有详细推导；网站显示多少内容，就保存可取得的内容。
zujuan.json 保留原题目字段，并增加 answerScreenshot、answerStatus、answerReason：
分别是答案图片路径、获取状态、未成功或不完整的原因。图片路径均相对于本批结果文件夹。
“部分保存”表示有图片未能获取，请结合原网页核对，不能当作完整答案。
单题网络或图片错误不影响其他题；遇到次数用完、权限不足、要求登录或人工验证，
会停止本批后续答案请求，
已抓取的题目和已保存的答案仍然保留。逐题原因可在总览中查看。
获取答案会使用登录账号的正常查看权限和额度，只尝试所选题目，不批量展开所有候选题。
具体额度以网站当前提示为准；重复运行也可能占用查看次数，请按需要设置取题数量。
题干中的公式保留编号占位，应结合截图阅读；截图红色编号不是原题条件。
总览只显示抓取结果，知识点、年级、难度仍需人工核对。

六、转发与移动
发给别人时，直接发送最初的完整 ZIP。对方解压后从“一键安装”开始即可。
不要把你使用后生成的 data 文件夹发给别人，其中包含配置和登录状态。
output 是你抓到的题，可按需要单独分享。
移动已经安装的工具前，先关闭工具浏览器，并整体移动文件夹。
在另一台电脑上使用，请用原始 ZIP 重新安装，并使用对方自己的账号登录。

七、常见问题
安装窗口出现网络错误：检查能否访问 nodejs.org、registry.npmjs.org，以及浏览器下载地址，再重试安装。
提示找不到依赖或运行环境：重新运行“一键安装”。
知识点不存在：核对 grade 和 points，或使用“查找知识点”。
抓不到题或数量不足：可能没有足够符合条件的题，也可能登录失效或网站页面变化。
出现人工验证：在浏览器中完成后再试。程序不会代替你绕过验证。
二维码超时：重新运行“登录组卷网”。
只看到题目、没有答案：先看总览里的状态和原因，再点“查看原题”检查同一账号能否打开解析。
  需要登录：重新运行“2-登录组卷网.cmd”，确认登录成功后再抓取。
  查看次数已用完：等网站额度恢复后再试，或查看账号现有权益。
  账号权限不足：当前账号无法查看该答案，程序不会绕过会员或权限限制。
  未获取到/获取失败：可能加载超时、网络异常、该题没有解析或网站改版。
  部分保存：部分图片加载失败，已保存内容可能不完整，可查看原网页或稍后重试。
  未启用：检查任务是否设置了 "answers": false。
旧批次不会自动补上答案；重新抓取会生成新的结果文件夹。
任务配置打不开或解析失败：检查英文标点、逗号、引号和文件扩展名。
公司电脑阻止脚本或浏览器：需要按所在单位的电脑管理要求处理，勿自行关闭安全软件。

八、源码和环境
project 内已包含原项目源码、知识点树和依赖锁定文件。
tools 内是本包的安装、运行和增强抓题入口。
.runtime 是首次安装生成的运行环境；data 是本机配置和登录状态；output 是抓题结果。
