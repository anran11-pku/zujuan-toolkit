# 组卷抓题工具

包含两套可以分别使用的 Windows 完整项目。两套都能抓取题目、配图，以及登录账号可查看的答案和解析，都不需要 Codex。

| 版本 | 适合用途 | API 密钥 | 使用说明 |
| --- | --- | --- | --- |
| [no-api](no-api/) | 保存题目和答案图片，在浏览器查看或打印 | 不需要 | [免 API 版说明](no-api/使用说明.txt) |
| [with-api](with-api/) | 在上述功能基础上，将已保存的图片识别为文字和数学公式 | 图片识别时需要 | [API 版说明](with-api/使用说明.txt) |

## 快速开始

1. 下载仓库 ZIP 并完整解压，进入你要使用的版本目录。
2. 双击 `1-一键安装.cmd`，等待安装完成。
3. 双击 `2-登录组卷网.cmd`，在工具浏览器扫码登录。
4. 根据需要通过 `3-编辑任务.cmd` 修改任务，再运行 `4-开始抓题.cmd`。
5. 双击 `5-查看结果.cmd` 查看本批题目、答案和获取状态。

API 版完成抓题后，先运行 `配置API.cmd` 填写自己的接口地址、密钥和视觉模型名称，再运行 `7-图片转文字.cmd`。识别结果保存在该批次的 `识别结果.md` 和 `ocr.json`。

两套项目支持 Windows 11 x64。首次安装需要联网下载运行环境和依赖，不需要预装 Node.js、Python 或 Git。每套项目有自己的配置、登录状态和输出目录。

## 版本与来源

- 基于 [malyjacob/zujuan](https://github.com/malyjacob/zujuan)，源码基线 `b7a275739e984a00c28278179ac995100a2dc2ff`。
- 保留知识点匹配、按难度优先选题、排除已选题、题干截图及题图保存等增强功能。
- 免 API 版采用已打包的 2026-10-23 含答案版本，发布时未改变其程序文件。
- API 版保留相同的抓题流程，另外提供独立入口，调用原项目已有的视觉 OCR 模块处理增强抓题结果。
- `project/` 中保留原项目文档、源码、编译产物、依赖锁定文件和测试；原项目的许可标识见其 `package.json`。

答案获取受网站登录、账号权限和查看额度限制。API 只负责识别已有图片，不会补造未获取的官方答案。公式识别可能出错，请与图片核对。

## 配置与数据

仓库只提供空白 API 配置模板，不包含任何真实密钥、Cookie、登录二维码、个人抓取结果或本机运行环境。`api.local.json`、`data/`、`output/` 和 `.runtime/` 均已被 Git 忽略。分享时发送原始下载包，勿把已使用目录中的登录状态和密钥发给别人。
