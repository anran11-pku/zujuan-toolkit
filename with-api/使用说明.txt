组卷抓题工具 · API 图片识别版

本版保留题目、配图、答案抓取功能，并复用原项目的视觉识别模块，
将已经保存的题目和答案图片转成文字、Markdown 和 LaTeX 数学公式。
不需要 Codex、Python 或其他 AI 客户端。只有“图片转文字”步骤需要 API。

一、首次使用
1. 完整解压并进入 with-api 文件夹，不要在压缩软件内运行。
2. 双击“1-一键安装.cmd”，保持联网，等待安装完成。
   自动安装本工具的 Node.js 和依赖，优先使用 Chrome 或 Edge。
3. 双击“2-登录组卷网.cmd”，在工具浏览器用自己的账号扫码。
4. 双击“3-编辑任务.cmd”修改任务；第一次可以保持默认，抓取3道初中题。
5. 双击“4-开始抓题.cmd”，等待题目和网站允许查看的答案保存完成。
6. 双击“5-查看结果.cmd”查看题目、答案图片和获取状态。
7. 双击“配置API.cmd”，填写设置后保存，再双击“7-图片转文字.cmd”。
   程序只识别最近一批题目的本地图片，不会再次抓取网站答案。
8. 到本批结果目录打开“识别结果.md”，或用编辑器读取 ocr.json。
   “5-查看结果”仍展示原始图片；识别文字另存在以上两个文件里。
9. 用完后可双击“6-关闭浏览器.cmd”。

二、API 怎么填
“配置API.cmd”会首次生成 api.local.json。填写三个字段：
visionApiUrl：服务商给出的兼容 OpenAI Chat Completions 的接口基础地址。
  一般以 /v1 结尾，不要填写完整的 /chat/completions 路径。
visionApiKey：你自己的 API 密钥。
visionModel：服务商支持图片输入的视觉模型名称，不能使用只支持文字的模型。
接口通常使用 HTTPS；本机代理允许 http://localhost 或 http://127.0.0.1。
保持英文双引号和逗号。密钥填在自己电脑的 api.local.json，不要写入示例模板。
基础抓题不调用模型。只有运行“7-图片转文字”时会把所选图片发送至你配置的服务商。
识别可能产生服务商费用，重复运行也会重新调用 API。
API 配置文件以及 data 中的本机配置均已被 Git 忽略，不能随使用后的目录一起转发。

三、任务配置
默认内容：
{
  "grade": "middle",
  "points": ["zsd5391"],
  "difficulty": "中档",
  "perPoint": 3,
  "maxPages": 3,
  "seen": []
}
grade：middle=初中，high=高中。
points：知识点编号，最多4个。可运行“查找知识点.cmd”寻找编号。
difficulty：基础、中档、较难；优先匹配，不足时使用其他难度补充。
perPoint：每个知识点1～10题；maxPages：每个知识点查看1～10页。
seen：需要排除的题目 qid 数组。
默认取答案；可增加 "answers": false 关闭答案获取。
若使用关键词，可将 points 设为 []，增加 "keywords": ["考查方法", "课题"]
和 "maxPoints": 1。自动匹配可能偏离要求，建议先用“检查配置.cmd”核对。
“检查配置”不抓题、不查看答案、不调用 API。

四、结果在哪里
output/日期-时间/index.html：题目和答案图片总览。
output/日期-时间/zujuan.json：原始抓取清单。
output/日期-时间/z01/question.png：第1题题目截图。
output/日期-时间/z01/answer.png：第1题答案、解析截图，获取成功时才有。
output/日期-时间/识别结果.md：API 识别出的文字与公式。
output/日期-时间/ocr.json：逐题识别文字和失败说明。
原始图片和 zujuan.json 不会因识别而改写。
同一批次重复识别会更新该批的识别结果.md 和 ocr.json。

五、常见情况
答案未获取：检查组卷网登录、会员权限和当日查看额度。限制原因会显示在总览。
没有答案图片：API 不会凭空补造官方答案，也不会自动解题。
部分保存：原答案图片可能不完整，文字识别同样可能不完整。
识别失败：检查接口地址、密钥、模型是否支持图片、网络和可用额度。
公式识别错误：请以原图为准，识别文字需要人工核对。
提示没有依赖：重新运行“1-一键安装.cmd”。
出现人工验证：在工具浏览器完成后重试；程序不绕过验证。

六、环境与分享
支持 Windows 11 x64。首次安装需要联网并预留约1GB空间；这是联网安装包。
安装到当前文件夹，不要求管理员权限，不需另行下载原项目。
分享时发送原始 ZIP，不要发送 api.local.json、data、output 或运行日志。
两套版本各自独立配置、登录和保存结果；另一台电脑需重新安装并登录。
